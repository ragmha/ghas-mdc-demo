# Security policy

This repository is an educational security demonstration. It deliberately
contains documented weaknesses so GitHub Advanced Security and Microsoft
Defender for Cloud can detect and remediate them.

## Seeded findings

Do not report findings listed in [the findings catalog](docs/findings-catalog.md).
They are constrained to synthetic data and are part of the demo.

## Reporting an unexpected vulnerability

Report any vulnerability outside the documented demo scenarios through the
repository's **Security** tab using private vulnerability reporting. Do not open
a public issue or include working exploit details in a discussion.

Never test this project against systems, subscriptions, repositories, or data
you do not own or have explicit permission to assess.

## Supported use

This project is not a production template and has no supported production
version. Run it only in an isolated, disposable environment and delete that
environment after the demonstration.
